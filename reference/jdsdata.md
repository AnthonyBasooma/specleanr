# Joint Danube Survey Data

A `tibble` Data on a five year periodic data collection within the
Danube River Basin. For more information, please visit
https://www.danubesurvey.org/jds4/about

## Usage

``` r
data(jdsdata)
```

## Format

A `tibble` 98 rows and 24 columns.

## Details

Species ecological parameters such as ecological ranges both native and
alien

## References

https://www.danubesurvey.org/jds4/about
